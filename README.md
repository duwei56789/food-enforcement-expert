# 食品行政执法专家 · Food Administrative Enforcement Expert

> 面向市场监管执法人员、法制审核人员与食品生产经营企业合规负责人的 Agent 型专家包。
> 精通食品安全法律法规、行政处罚程序、案件调查取证与企业合规审查。

## 一句话说明

**是什么**：一个可直接装载到 WorkBuddy 专家中心的 AI 专家包（Agent 型），把"法条解读 → 违法事实认定 → 处罚裁量 → 执法文书 / 合规整改"串成标准工作流。

**为什么重要**：食品行政执法案件的定性、量罚高度依赖"违反条款 / 处罚条款"的严格对应与程序合法性，人工检索易漏易混。本专家把构成要件、裁量情节、行刑衔接触发点固化为输出规范，降低定性偏差与文书瑕疵风险。

## 核心能力

| # | 能力 | 交付内容 |
|---|------|----------|
| 1 | 🔍 法条解读 | 锁定"违反条款"与"处罚条款"对应关系，标注法律层级与生效版本，解释构成要件（如"超过保质期""非食品原料""掺假掺杂"），提示易混淆点（无证 vs 许可证过期、生产 vs 经营责任） |
| 2 | 🧾 违法事实与情节分析 | 按主体 / 行为 / 客体 / 主观过错梳理事实，逐项核对法定从轻、减轻、从重情节，评估危害后果及"情节严重""足以造成严重食物中毒事故"等升级情形 |
| 3 | ⚖️ 处罚裁量建议 | 处罚种类与幅度（警告 / 没收 / 罚款区间 / 责令停产停业 / 吊销许可证）、罚款基数计算（货值金额 vs 违法所得）、说理文本、行刑衔接触发提示 |
| 4 | 📄 执法文书生成 | 立案审批、现场检查笔录、询问笔录、责令改正、处罚告知、听证告知、处罚决定书、结案报告的模板、必填字段、证据清单与时限送达备注 |
| 5 | 🏭 企业合规整改 | 对照日常监督检查要点表输出差距清单、整改路线图、制度与台账模板（进货查验、健康管理和自查、召回）、标签与宣传合规要点 |

## 知识领域

- **实体法**：《食品安全法》及实施条例、《农产品质量安全法》、《生猪屠宰管理条例》；保健食品 / 特医食品 / 婴配乳粉注册备案与标签广告规则；《反不正当竞争法》《广告法》《消费者权益保护法》《反食品浪费法》等交叉法。
- **程序法**：《行政处罚法》《行政强制法》《市场监督管理行政处罚程序规定》《市场监督管理行政处罚听证办法》；行刑衔接规定与司法解释。
- **裁量基准与案例**：各省级裁量权适用规则、市场监管总局"铁拳"行动与指导性案例、免罚轻罚清单。
- **调查取证**：现场检查 / 抽样检验 / 询问 / 先行登记保存 / 查封扣押规范，检验报告证据效力与复检，电子数据固定。
- **企业合规**：HACCP、进货查验记录、从业人员健康管理、自查与追溯体系、标签合规（GB 7718、GB 28050）。

## 输出规范

案件类输出统一采用结构化格式：**案件名称 / 违法事实概述 / 适用法律法规 / 处罚结果 / 执法机关**。

- 严格区分"违反条款"（定性）与"处罚条款"（量罚），并标注条文层级与生效版本。
- **结论先行 + 法条支撑 + 风险提示** 三段式；引用数据或金额时注明来源。
- 触及刑事追诉标准（如非法添加有毒有害物质）时提示"行刑衔接"路径，不自行定性量刑。

## 安装 / 使用

### 方式一：WorkBuddy 专家中心（推荐）

1. 还原头像：`python scripts/restore_avatar.py`
2. 将整个 `food-enforcement-expert/` 目录放到专家插件目录下，例如：
   ```
   C:\Users\<用户名>\.workbuddy\plugins\marketplaces\my-experts\plugins\food-enforcement-expert\
   ```
3. 运行专家注册脚本使其可见：
   ```bash
   python3 scripts/register_expert.py <expert-dir>
   ```
4. 在左侧「专家」中搜索 **食品行政执法专家** 并发起会话。

> `register_expert.py` 属于 WorkBuddy 本地专家目录的配套脚本，不随本仓库分发；若你的环境未提供该脚本，直接把目录放入专家插件目录后重启客户端即可被扫描到。

### 方式二：仅复用提示词

直接把 `agents/liaoge-food-safety-advisor.md` 的正文作为 System Prompt 装载到任意支持自定义指令的 Agent / 大模型客户端中使用。

## ⚠️ 使用边界与免责声明

1. 本专家输出**不替代正式法制审核、负责人集体讨论与司法最终裁判**，仅供办案参考与企业合规自查。
2. 引用法条须核对**现行有效版本**；各省裁量基准存在差异时，**以属地规定为准**并提示核实。
3. 涉及非法添加有毒有害物质等可能触及刑事追诉标准的情形，仅提示"行刑衔接"路径，**不作刑事定性与量刑判断**。
4. 所有建议保留专业判断余地，避免对具体个案作绝对结论；实际执法请以有权机关决定为准。
